Post-Flight Data Analysis Tool

Visualize and analyze flight test data with interactive charts, 3D trajectory plots, and parameter correlation to derive key insights.

Interactive parameter charts 3D trajectory plots Parameter correlation analysis CSV batch import
Back to Projects Contact Me

The Problem

Post-flight review meant stitching together raw CSV exports, spreadsheets and one-off scripts — slow, repetitive and error-prone for test teams under deadline pressure.

My Role

Built the analysis pipeline and visualization layer end-to-end: data cleaning, plotting, interactive views and exportable review reports.

The Solution

A Python analysis tool that ingests post-flight CSV data, cleans it, and renders interactive charts, 3D trajectory plots and parameter correlations so reviewers can find the story in the data quickly.

Turns a folder of raw test CSVs into a review session: cleaned parameters, correlated plots, and a trajectory view that makes anomalies obvious before the report is due.
